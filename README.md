# DateDrop 📅

Turn school newsletters into calendar events.

DateDrop is a Chrome extension designed to help parents quickly find important dates from school newsletters and add them to their personal calendars.

## 🎯 Problem

Schools share important dates in different formats, including:

- Smore newsletters
- PDF newsletters
- School webpages
- Email newsletters

Parents often have to manually find these dates and create calendar events.

DateDrop aims to make this process simple.

## 🚀 How It Works

```text
School Newsletter
       ↓
    DateDrop
       ↓
Find important dates
       ↓
Review events
       ↓
Add to Calendar
